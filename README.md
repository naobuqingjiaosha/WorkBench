# 工作台（WorkBench）

工作台是一款面向本机单用户的行政管理与项目实施工具，用于组织工作事项、办理期次、项目阶段、业务资料和成果文件，并提供AI辅助起草与资料检索能力。

项目以Windows本地使用为主要场景，目前处于开发阶段。

## 解决什么问题

将分散的工作要求、参考资料、模板和办理记录关联起来，在同一项工作中准备材料、保留修改、生成成果和回顾历史，减少重复查找和填写。

## 主要能力

- **工作组织**：按工作类型建立事项，分别管理周期工作的期次和项目的阶段。
- **材料准备**：参考历史内容，编辑检查草稿，结合模板生成Word、Excel等成果。
- **工时与台账**：处理月度工时材料和年度台账，关联输入、计算或编辑结果及文件版本。
- **文件与知识**：管理附件、模板、参考资料和成果，提供检索、预览及适用的解析能力。
- **AI辅助**：基于选定资料进行问答、起草和信息整理，支持配置本地或外部模型服务。
- **工作记录**：保存工作情况及其来源，用于后续查询和回顾。

以上是项目能力范围，具体实现、验证及各运行版本的可用范围见[开发进度](DEVELOPMENT_PROGRESS.md)。

## 设计原则

- 工作、期次、阶段与成果分别管理，历史资料和版本可以追溯。
- AI建议和已确认事实分开；未知内容保留未知。
- 材料准备以生成和下载为操作终点，不把生成文件视为实际报送或业务完成。
- 业务数据在本机保存，源码、私有配置和测试资源分别管理；外部模型调用按选定资料范围处理。

## 技术概览

采用React与TypeScript前端、Node.js与Fastify后端，使用SQLite及本地文件系统保存数据。后端按业务模块组织，提供模板、文档处理、检索、OCR和模型接入等共用能力。
