# 模板制作指南

> 2026-10-16 补充：Word、Excel均可使用`{#循环 集合名}`…`{/循环}`。Excel循环必须占据工作表最后一行数据，首尾标记放在同一行，集合为最多2000条对象的JSON数组；循环行不能合并、不能含公式，后方不能有表尾内容，统计公式可放独立工作表。缺集合时保留待填提示，空数组清空模板数据行，数字保持数字类型。月检单次表与项目台账从检查记录生成，月度／年度汇总从期次入口生成。工时表走专用计算入口，不使用普通替换代替工时算法。下文固定编号变量是旧模板兼容方式，新台账优先使用上述循环。

> 目标：让大模型只填"该变的内容"，排版、字体、页眉页脚、表格样式一点不动。

## 一、核心只有一条规则

**把模板里每次都会变的内容，换成一对英文花括号包起来的变量名。**

```
改之前：                          改之后：
┌────────────────────────┐      ┌────────────────────────┐
│      某某单位          │      │      {单位名称}        │
│   月度安全检查记录表    │      │   月度安全检查记录表    │
│                        │      │                        │
│ 检查月份：2026年3月     │      │ 检查月份：{检查月份}    │
│ 检查区域：办公楼一至三层 │      │ 检查区域：{检查区域}    │
│ 检查人：张工            │      │ 检查人：{检查人}        │
│ 检查日期：2026年3月15日 │      │ 检查日期：{检查日期}    │
│                        │      │                        │
│ 一、检查情况            │      │ 一、检查情况            │
│ 消火栓压力正常，应急照明 │      │ {检查情况}             │
│ 抽查6处均可用…          │      │                        │
└────────────────────────┘      └────────────────────────┘
```

改完直接上传，系统会自动把 `{单位名称}` `{检查月份}` … 全部扫出来，生成填写表单。

## 二、语法速查

| 写法 | 作用 | 例子 |
|---|---|---|
| `{变量名}` | 普通替换（最常用） | `{项目名称}` → 某局机房改造项目 |
| `{变量名\|默认值}` | 变量为空时用默认值 | `{编制人\|办公室}` |
| `{_今天}` `{_本月}` `{_工作台编号}` `{_工作台名称}` | 系统变量，自动填，不用你输入 | `{_今天}` → 2026年3月15日 |

**必须注意的三点：**

1. **用英文花括号** `{}`，不要用中文书名号 `【】`、双花括号 `{{}}` 或方括号 `[]`。
2. **变量名里不要有空格**，也不要有花括号。中文、英文、数字、下划线、横线都可以。
3. **一个变量必须在同一个段落里写完**。Word 有时会把一句话拆成多个"格式块"，如果变量被拆开就扫不到。
   遇到这种情况：把 `{变量名}` 整段选中，剪切，再粘贴回原位（会合并成一个格式块），或者把变量单独放一行。

## 三、变量怎么命名

三条原则，目的是让"同一个东西在所有模板里都叫同一个名字"，这样才能自动带出项目信息。

### 1. 用中文，和模板里的人话一致

`{项目名称}` `{合同编号}` `{到货日期}` `{检查人}` —— 一眼就知道该填什么。

### 2. 同一个概念，全系统统一叫法

| 概念 | 统一用 | 不要用 |
|---|---|---|
| 项目名 | `{项目名称}` | 工程名称、项目名、本工程 |
| 甲方 | `{建设单位}` | 甲方、业主、委托方 |
| 经办人 | `{负责人}` | 经办、负责、主管 |
| 日期 | `{检查日期}` `{到货日期}` 等具体名 | `{日期}`（太笼统，容易带错） |

系统和项目信息自动对应的变量（新建工作台时填过的信息会自动填入）：

| 模板变量 | 自动来自 |
|---|---|
| `{项目名称}` | 工作台名称 |
| `{负责人}` / `{检查人}` / `{编制人}` / `{经办人}` | 工作台负责人 |
| `{建设单位}` / `{甲方单位}` | 工作台对接单位 |
| `{合同编号}` | 工作台合同编号 |
| `{开工日期}` | 工作台开始日期 |
| `{检查日期}` / `{编制日期}` / `{报告日期}` | 当天日期（中文格式） |
| `{检查月份}` / `{月份}` | 当月 |

其它变量由大模型根据你给的资料和"特别要求"填写。

### 3. 成段文字用长文本变量

像"检查情况""验收结论""存在问题"这类要写几句话的，命名成 `{检查情况}` `{验收结论}` `{存在问题}`，
到「模板库 → 设置」里把它的类型改成 **长文本**，填写界面就会给一个大输入框，模型也会写得更充分。

## 四、三类模板的具体做法

### A. 纯文字公文（通知、请示、报告）

在 Word 里正常排版，标题、正文、落款都保持原样，只替换会变的部分：

```
                          {发文机关}
                    关于{事由}的通知

{主送单位}：

    根据{依据}，经研究决定，{主要事项}。

    一、{措施一}
    二、{措施二}

    请{执行要求}。

                          {发文机关}
                          {成文日期}
```

变量：`{发文机关}` `{事由}` `{主送单位}` `{依据}` `{主要事项}` `{措施一}` `{措施二}` `{执行要求}` `{成文日期}`

### B. 表格类记录表（检查表、验收表、台账）

Word 表格里，**每个单元格单独放一个变量**：

| 序号 | 检查项目 | 检查结果 | 备注 |
|---|---|---|---|
| 1 | 消火栓 | `{消火栓结果}` | `{消火栓备注}` |
| 2 | 应急照明 | `{应急照明结果}` | `{应急照明备注}` |
| 3 | 配电箱 | `{配电箱结果}` | `{配电箱备注}` |

> 提示：表格里的变量最好一个单元格一个，不要把一行的多个单元格合并成一个变量名——
> 那样模型给的是一整段文本，塞进单元格会很难看。

如果同类型的行数不固定（比如设备清单有 8 台也有 20 台），
建议做成**固定行数 + 编号变量**：`{设备1名称}` `{设备1型号}` `{设备1序列号}` … 空行由你生成后手工删。

### C. Excel 表格（台账、汇总表、计算表）

改动方式和 Word 一样，**单元格里直接写变量**：

| A | B | C |
|---|---|---|
| 项目名称 | `{项目名称}` | |
| 合同编号 | `{合同编号}` | |
| 本月完成投资 | `{本月投资}` | 元 |

公式、格式、列宽、合并单元格、条件格式全部保留——系统只是把单元格里的文本换掉，不动别的。

## 五、上传之后做什么

1. 「模板库」列表里点 **扫描变量** → 确认变量都扫出来了（会高亮显示）。
2. 点 **设置** → 给每个变量补：
   - **界面标签**：填写时显示的名字（默认就是变量名）
   - **类型**：短文本 / 长文本 / 日期 / 数字
   - **是否必填**
   - **填写提示**：告诉模型你想看到什么格式，例如"填 2026年3月 这样的中文格式"
3. 保存。下次生成时这些提示会一起发给模型，输出质量明显更好。

## 六、做不好的情况怎么办

| 现象 | 原因 | 解决 |
|---|---|---|
| 扫不到变量 | 用了中文括号 / 双花括号 | 改成 `{}`；或告诉我，我给扫描器加规则 |
| 扫到一半的变量 | `{变量}` 被 Word 拆进了多个格式块 | 重打一遍变量，或把它单独放一行 |
| 生成后变量旁边空格多了 | Word 的 xml:space 处理 | 生成后手工调一下，或在模板里不留多余空格 |
| 上传提示"不可填充" | 是 `.doc` / `.xls` 老格式 | 另存为 `.docx` / `.xlsx` |
| 图片/扫描件想套用 | 图片无法填充 | 图片作为参考资料/证据归档；要套版就重建成 Word 模板 |

**最后一句实话**：模板做得越规范（变量命名统一、一个语义一个变量），大模型生成的质量越高。
这套系统的设计就是"先固化，再智能"——模板和流程标准化了，AI 才有稳定的发挥空间。
