这是 Windows 本机、单用户的工作台。业务包括安全、清廉监督、项目实施、部门工时及工作记录方向；技术是 React + Vite 前端、Fastify + TypeScript 服务、SQLite 元数据与磁盘业务文件。用户需要少填、可修改、可追溯的实际材料，不需要额外增加报送和强制办结步骤。
