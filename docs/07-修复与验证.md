# 修复与验证说明

本轮针对审查中的业务错误、数据一致性、归档恢复、AI 目标、安全边界、备份和测试隔离作修复。

- 使用 Node 24，安装依赖后执行 npm test、npm run typecheck、npm run build。
- npm run dev 通过 Vite 代理连接本机 8787 后端；使用自定义端口时同步修改代理。
- npm run test:all 自动创建独立数据库与文件目录，不要直接运行旧 E2E 文件。
- npm run pack 默认只生成程序包；停止服务后用 npm run pack -- --with-runtime-state 生成含个人资料和凭证的完整备份。
- 迁移包的 dataRoot 统一指向包内 data/files，解压后按快速上手安装运行。
- 模板库和我的工作均有归档入口；缺失的历史文件应从旧备份找回，系统不会凭空重造。
- 周期工作保存待完成周期。补做旧周期后如果仍有欠办期，会继续显示提醒。
- 项目信息草稿保留在当前浏览器会话，关闭浏览器前请保存。
- 外部模型会接收当前操作提供的文字/图片；仅本机服务商可以在本地处理。
- API 修改请求需 x-workbench-token；从 /api/session 取得本机当前会话 token。

历史缺失模板和未能确定的旧周期完成归属仍需人工核对，迁移不猜测丢失内容。
