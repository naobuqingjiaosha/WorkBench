## 当前源码中的 13 页布局

按用户提供的 01–13 图核对布局。原图宽 1672、高 941 像素。该尺寸下侧栏宽 244 像素，正文面板从 x=264 开始。桌面主操作位于页头，暖白背景上的白色面板采用统一的表头、细分隔和蓝色操作按钮。窗口收窄时主栏与辅助栏依次排列。长内容随页面滚动，控件支持键盘焦点，弹窗在短窗口中可滚动到操作位置。

首页将待办和继续办理作为主列，右侧依次是工作概览、近期截止与月历、最近成果、随手记表单。桌面可用区至少 1000×600 CSS 像素时，两列六个模块同屏；低于门槛时保留正常页面滚动。截止列表、完整月历、随手记补充字段在弹窗内查看，日期来自现有记录。首页大屏的最新截图见[3860×2140](../../outputs/home-viewport/after/3860x2140.png)与[2560×1660](../../outputs/home-viewport/after/2560x1660.png)。模板分类来自已有模板数据，字段映射和后台参考资料维护仍各有入口。文件按真实类别和关联工作筛选。AI 助手可选取有消息记录的会话，也可单独查看业务问答证据。系统配置保留用途模型、后台维护和引用直达。

### 导航、焦点与滚动

- 首页搜索在结果上直接预览命中的文件或模板。关闭后回到原搜索。工作列表固定展示截止日期所属的期次入口，列表历史保存筛选、分页和滚动位置；打开、刷新或返回期次时均使用链接中的标识。
- 窄屏侧栏可用关闭按钮、Esc、遮罩或再次选当前页收起。工作记录详情以弹窗呈现，关闭后回到触发条目。通用折叠卡片支持键盘，在展开与收起时传达当前状态。设置分栏分别记录位置，低频维护按需展开。
- 桌面并排选择行政管理工作或项目工作，小屏上下排列。选定有效类型后才能创建。流程规范同一时刻展开一个阶段，可从当前编辑区保存，窄屏返回类型列表后焦点回到原类型。月检未绑台账时收起导入和绑定表单，检查区域标题标明本期待确认草稿与已确认记录的数量。工作页内的检查草稿直接在原处编辑。
- 部门工时的逐日操作在侧边弹窗中显示目标人员和日期。保存或取消后回到原行。存在未保存依据或份额时，关闭须先确认。独立页提示返回所属工作换期，嵌入页使用上方期次选择。

### 表单反馈与信息展示

文件、模板和服务商设置的编辑器复用保存及离开保护。对话允许保留未发送文本；Enter 发送、Shift+Enter 换行，中文输入法组合输入保留选词操作。新输入的服务商密钥默认隐藏。文件列表区分大小与版本状态，优先留足搜索词宽度；模板分别处理归档、无匹配和变量清单状态。回收站展示全库类型数和当前结果数，单项永久删除默认保留磁盘文件。

### 验证方式

打开本机 [逐页原图对照](../../outputs/design-review-13/index.html)，可切换 13 页、修改前后和 1672×941、1366×650、390×844 三档修后视口。点击图片打开原尺寸；两版实际页面均使用独立 SQLite 与同一组合成资料。当前共享浏览器回归使用根目录的 `npm run test:browser`，以临时 SQLite 和合成资料核对落点、输入、焦点、保存及返回。逐日调整与阶段编辑用例包含窄窗口，实际 Windows 日常构建及本批验证范围查[开发进度](../../DEVELOPMENT_PROGRESS.md)和[工作日志](../management/WORK_LOG.md)。

### 100%缩放紧凑布局（2026-10-24历史）

当时用户要求整体缩小，并在浏览器100%缩放下看到各页框架与主要操作。此要求覆盖此前按PNG原尺寸设置组件大小的部分，保留首页约7:5双栏及模块次序。统一采用184px侧栏、13px正文、32px常规控件；不修改浏览器缩放，不用CSS zoom或整体transform缩放。长列表、表单和历史记录在各自面板内滚动，保存、导出和聊天输入保持可见；弹窗高度受当前窗口约束。

当时新增最后加载的compact.css控制全局密度。工时页独立划分输入、结果和操作区，人员/逐日/核对标签始终可见。八个主页面在1280×600、1366×650、1440×800、1920×900浏览器内容区验证无框架溢出；台账、工时、项目阶段、长流程列表及AI/上传弹窗在1366×650检查保存/导出按钮可见与区域滚动可达。小于1000px的窄屏保留单列和页面滚动，不承诺任意数据量同屏无滚动。

验证入口：`node scripts/check-viewport-density.mjs`（7组），`node scripts/check-dashboard-layout.mjs`（5组紧凑首页），`node scripts/check-ui-design.mjs`（10组交互）。截图与结果分别见[紧凑布局](../../outputs/ui-implementation-20261024/compact-100/results.json)、[紧凑首页](../../outputs/ui-implementation-20261024/home-compact/results.json)；均使用隔离或浏览器拦截样例。前端类型检查和隔离构建通过，未切换日常发布。

### 首页布局复核与纠偏（历史尺寸证据）

以下为紧凑调整之前的检查记录，原尺寸和边界误差不再作为当前大小验收标准。

## 历史有限后端调整

- 台账建议和检查草稿建议接受当前编辑快照，不隐式保存；限定字段并检查源记录修订。
- 两表生成接受 `kinds` 和 `revision`，返回逐文件 `results`；成功文件保留，只重试指定失败项。
- 生成前检测外部变化，扫描令牌参与同步校验；相同映射内容不重写文件。仅改监督情况表“具体内容”不会改写工作记录表“检查内容”。
- 同步返回操作标识和逐对象结果；写入某对象失败后停止后续文件写入，已完成结果明确保留，重新读取后再处理剩余对象。
- `GET /api/periods/:id/ledger/documents/:doc/preview` 读取所选实际文件的映射字段，不以编辑缓冲冒充旧版本。

## 历史隔离预览入口

在仓库根执行：

```powershell
node scripts/preview-ui-design.mjs
```

默认地址 `http://127.0.0.1:18894`。脚本先检查端口，再构建到 `.tmp/ui-design-preview/web`，初始化匿名样例并启动隔离服务。数据、文件、备份均在 `.tmp/ui-design-preview`；自动备份定时器关闭。可用 `WORKBENCH_UI_PORT` 指定其他非 8787 端口。再次运行复用匿名预览数据，不重置记录。

2026-10-24按用户要求清空此预览环境的测试记录和文件，并保留 `.empty-preview` 标记。永久删除被自动审核拦截，原数据已移至 `.tmp/ui-design-cleared-20261024-01`，保留可恢复副本，不再供预览使用。存在该标记时，启动脚本跳过示例灌入，由服务初始化空业务数据库；后续重启不会重新生成示例。上述交互验证依赖原样例，不能直接在已清空的预览上重跑。

不要用指向日常 8787 的普通前端开发代理写测试数据。此预览不切换 `current-release.json`，也不覆盖日常 `packages/web/dist`。

## 2026-10-24 历史验证的能力边界

- 未调用真实模型，未重新进行 Word 分页、Excel 原生重算/打印或真实整月业务验收。
- 台账 XLSX 预览为实际映射字段，普通文件沿用现有图片/PDF/文本/Excel 内容预览；不宣称完整 Office 排版一致。
- 台账旧文件没有完整的生成源修订/模板版本元数据，不伪造编号；显示实际文件标识、时间、当前基线差异。通用文书沿用已有版本链。
- 没有新增后台持续生成任务或结果查询服务。网络中断时显示结果待核实，先核对关联文件；不自动重复生成或声称后台继续成功。
- 同步操作标识和结果用于本次响应及界面核对，尚不是跨重启的操作日志。手动合并、一键整体回滚未接入；保留工作台/采用指定文件后重新核对。
- 旧流程编辑弹窗通过共享离开保护保留输入；未提供可复用保存回调的旧表单会要求回原编辑区保存，不能伪造“保存并离开”。
