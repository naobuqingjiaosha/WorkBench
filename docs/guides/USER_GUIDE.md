# 使用说明

文档ID：GUIDE-USER。版本：1.19。更新：2026-11-12。性质：工作台操作手册。下列页面名称与布局对应当前工作区源码，目标设备的已发布构建见[开发进度](../../DEVELOPMENT_PROGRESS.md)。

## 1. 进入与理解页面

已启动的日常服务通过[本机工作台](http://127.0.0.1:8787)访问。需要核对尚待确认的 13 页布局时，可直接打开[隔离实页图册](../../outputs/ui-reference-13-20261112/index.html)。正式运行沿用根目录“启动工作台.cmd”或等价的 `npm start`，它会使用当前检出目录的源码。启动与切换见[安装指南](INSTALLATION.md)，故障处理见[运维手册](OPERATIONS.md)。

13 页布局的首页左侧是待办和最近五项在办工作；待办每页五条，点击对应操作进入工作或完成个人待办。右侧可查看工作概览、近期截止、月历和最近成果，也可直接输入并保存随手记。顶栏保留完整工作记录入口。搜索结果中的文件和模板可直接预览，关闭后回到原结果。通知可定位到待办所在页。

“我的工作台”列表底部可翻页。点击“继续办理”进入列表所示截止日期对应的期次，窄屏可在名称旁找到该操作。切换期次后，刷新或使用浏览器前进、后退会显示链接指定的期次。从详情返回列表可接着使用原筛选和页码。窄屏打开导航后，可用关闭按钮、Esc 或点击遮罩收起。

“我的工作台”进入具体工作；“流程规范”维护类型和适用规则；“知识库”的模板库维护可重复使用的Word/Excel；助手用于问答和起草。实际可见入口须核对本机运行版本，不能按源码候选截图认定日常版已更新。

## 2. 新建工作

第一步选择行政管理或项目工作，选定性质后再填写并创建。只想记下发生的事可直接用“随手记”。项目再选择信息化/工程目录和具体类型；目录只是分类，实际流程由具体类型决定。填写已知的名称、背景等信息，按需要选择适用模板。流程配置候选只提供已发布且未停用类型，新工作采用选择时的发布配置；如提示版本变化，点击“刷新可用配置”，核对所选类型后重试，基础输入保留。一份模板都不选表示当前工作暂不使用模板，不自动采用整个模板池。

工作、月份/季度/年度、项目阶段是不同范围。进入材料前先确认当前是哪项工作、哪一期或哪个阶段，避免把历史资料当成本期。

### 2.1 维护流程配置

1. 打开“流程规范”，选择类型或点击“新增 / 复制类型”。空白或复制均先建草稿；复制只取已发布规则与模板引用，不复制业务资料。
2. 点击所需阶段展开编辑。保存草稿按钮位于顶部操作栏，向下滚动仍可操作。在窄屏选择类型会直接显示该类型的详情，点击“返回工作类型”回到原项。可编辑类型说明、导航分类、阶段顺序/要求、影像、模板和周期规则。材料明确选择外部材料、参考资料或生成成果；旧规则兼容项在复制或改名后应明确用途。已有工作使用的类型不能直接更改领域、业务分类、办理方式或执行器。专用月检能力不会因复制或改名获得。
3. “保存草稿”只保存编辑；不完整内容可以保存，结构错误或发布前缺项会提示。离开时可继续、放弃未保存输入或保存并离开。另一个窗口已改时，保留本页内容，先“核对最新状态”，比较后采用最新内容或明确保留本页整份配置、以最新修订为基线重新保存。
4. 保存后“检查差异并发布”，检查实际变更、填写变更说明，再“确认发布配置”。这是本地规则版本发布，不是软件部署。期间等待完成，失败保留草稿；网络结果未知先核对最新状态。历史版本保留，放弃已保存草稿须明确确认。
5. “停用新建”只从新建选项中移除类型，旧工作仍可查询/办理且周期继续；“恢复新建”恢复现有发布版，不自动发布未完成草稿。工作列表仍保留停用类型分类。

发布新规则默认只影响以后创建的工作。在已有工作详情展开“流程配置更新”后点击“预览配置差异”，查看可应用项和禁止原因，再勾选指定范围及确认框，点击“确认应用所选范围”。新增阶段仍待开始；显示名称、说明、顺序及文书要求仅在未使用的安全阶段可改，目录不搬移。既有材料/影像要求、已完成或有业务引用的阶段不可覆盖，不能以配置更新改历史定稿。周期工作须填写明确未来生效期并重新预览；频率不变且晚于今天、已有期次和已排定规则。应用不生成期次、不改旧期次，后续正常生成才采用对应规则。已排定规则不原位撤销/修改，可安排更晚的不同规则；旧高级排期保存会明确拒绝覆盖。页面记录实际部分范围，不代表整项工作全部升级。失败保留选择，可重试；冲突须重新预览并再次确认。慢请求期间等待完成，取消未保存选择须明确放弃。旧实例来源不明确时保持原兼容逻辑。模板内容或变量配置变化会与已保存指纹冲突。对有明确发布来源的工作/阶段，“预览阶段模板要求变更”与“流程配置更新”执行同一保护；漂移、归档或缺失会禁用应用，预览后才发生变化也会拒绝确认，不会把新文件指纹自动当成批准。应核对模板并明确重新发布适用配置，再重新预览；不能靠重试强行覆盖旧引用，历史成果保留。配置不生成检查/工时事实，也不管理实际报送。阶段模板未指定的新实例保持空绑定。

周期配置的多项生成成果可以共用同一模板。生成窗口的“本次对应成果要求”明确选择这份文件对应哪项；只更新所选要求和该项版本链，不自动满足其他项。“逐项成果要求”分别显示必备/选备与有效成果状态，导入或已有文件可在对应行明确关联；同模板或同名不代表已经关联。单项可自动选中；多项未选时不能保存。缺任一必备项仍不可完成，但不阻止其他草稿保存或下载，生成也不自动办结。关联保存进行中请等待，导航或返回会提示留在原页；失败保留选择并显示错误，可点“重试关联”，或“放弃未保存选择”恢复已保存关系。离开确认中的“保存并离开”须保存成功才离开；“不保存离开”只丢弃未保存选择，不删除既有关联。空选项不是清除关联操作。

### 2.2 提醒与项目

行政类型没有独立期次规则时，可设置每月、每季度首月或每年的提醒。填写日号和提前天数，进入提醒窗口后从首页打开，在所属工作点“确认本次提醒已处理”后查看下次提醒日期。只需记录一件零散工作的原话时，用首页随手记。

在办项目在“流程与清单”中选阶段，上传对应清单材料并核对。需要时在阶段备注处保存说明，再点“标记本阶段完成”；选择“暂不适用”须填写依据。周期工作的“确认本期办理完成”在所选期次内容上方，可先查看缺项。上传、核对、完成阶段和结束工作分别操作。历史项目在新建时选择历史补录，发生日期只填已知值；进入材料核对查看档案缺口。收起在办工作可恢复到原列表，正式归档须业务已结束且相关材料齐备。

## 3. 月度检查材料

未绑定年度台账时，展开“尚未绑定年度台账 · 导入或绑定”配置台账。检查区域的标题同时显示草稿和已确认数量，展开后可直接在工作页继续编辑。登记实际检查仍然需要确认事实。

清廉工程月检优先从期次内“年度台账与月度检查”开始：导入/绑定原年度台账 → 选择项目并查看历史 → 保存本月事项和实际情况 → 标记两条小微权力记录 → 补齐/采用模型建议 → 从同一记录生成工作记录表与监督情况表。允许同项目同月多条；未选项目不自动结束。外部Excel保存后，点击读取修改并同步，冲突时选择保留内容。完整步骤见[月度工作指南](MONTHLY_DEVELOPMENT.md)。

以下共享草稿入口继续保留，用于原有材料准备场景：

1. 进入月检工作，选择本月，点击“新建检查记录”。也可在助手选中月检工作后说“帮我准备本月检查材料”。
2. 系统先参考同工作历史，标明来源。没有历史时可先填写项目背景，不必补造检查日期或结果。
3. 模型可用且资料使用范围允许时给出文字建议；用户可以直接编辑，也可在共享草稿卡片选择修改范围并提出要求。
4. 未开展或缺少事实时保存草稿、下载待确认文件；不得把建议当已开展的检查。
5. 实际情况明确后，集中核对并“采用并生成文件”。项目、日期、主题、内容、结果齐全才会形成实际检查记录；特定模板所需检查人等仍需补齐。
6. 选择适用的单次模板生成，逐份查看结果。月度/年度汇总从对应汇总入口生成，不能拿汇总模板当单次模板。
7. 下载后检查内容和版式。Word页面摘要不等于完整分页预览，Excel页面预览不等于桌面打印和公式重算。

可以直接取得草稿文件，不需要登记报送日期、上传回执或先点击本期完成。工作台不管理是否实际报送。

安全例会从对应工作选择当期，填写会议内容，按需上传参考材料，选择适用模板生成并下载纪要。在同一期的成果区可再次找到文件。季度汇报先勾选本季度所需来源期次并保存范围，模板可使用“季度参考范围”“范围内已确认检查次数”“范围内已确认检查”。缺少本月事实的草稿只作参考。

## 4. 修改、旧文件与恢复

编辑文件详情的备注或标题、模板设置和模型服务商设置时，关闭窗口或按 Esc 会检查未保存输入。在保存失败的情况下可留在原表单重试。回收站的类型数量按全库统计；筛选只影响显示的记录。“清空”处理全部类型，确认前核对范围和保留期。单项永久删除默认保留磁盘文件，需要删除允许范围内的文件时另行选择。

- 草稿修改后保存；其他入口已更新同一草稿时，系统可能提示冲突。保留自己的输入，核对最新内容后再保存，不能反复强行覆盖。
- AI建议与原文可对照，仅采用需要的修改。请求失败时原稿保留，可人工继续。
- 历史来源被更正或删除时，先切换来源或解除引用，不继续把旧引用当有效依据。
- 内容或模板变化后旧文件仍保留，可能显示待更新；再次生成取得新版本。不能只看旧文件名判断当前内容正确。
- “生成成功”“定稿”“检查已开展”“业务结束”含义不同。可自愿保留核对后的定稿，草稿下载不依赖它。

## 5. 项目、季度材料与工时

| 场景 | 使用要点 |
|---|---|
| 在办项目 | 按实际类型阶段处理，区分参考资料、生成件和真实合同/签章/验收证明 |
| 历史项目 | 补录已有事实和资料，不重走历史；未知结束日期不编造 |
| 季度材料 | 明确选择来源工作和期次；检查跨期、缺资料与计划/实际差异，再编辑正文 |
| 部门工时 | 从所属月度期次进入，先在上方选择期次，保持资料月份与期次一致，使用页面顶部研发/考勤/模板入口；确认名单、应计日期和扣薪例外，生成后手动或经模型建议修改，再核对导出。完整步骤见[月度工作指南](MONTHLY_DEVELOPMENT.md) |
| 制度参考 | 默认关闭；需要时明确提出本次参考制度，并人工判断适用范围 |
| 工作记录候选 | 源码支持原话录入、按关联工作筛选、查询、更正和撤回；是否可用须按当前设备的在线构建核对，源码候选不属于日常操作承诺 |

“逐日分配”中点击某一行的“调整”，在右侧核对人员和日期，填入修改依据后选择“保存此日工时和项目”或“保持总工时，更新分配”。关闭有改动的编辑器时，可继续编辑或明确放弃；关闭后回到原行。独立工时页换月先点“返回所属工作”，工作内嵌页用上方期次选择。

按整小时分配部门工时。多个明确项目均分后，余数按所选项目的顺序分配，可手工改份额并保持当日总数。研发或扣薪出现无法整分的余额时先核对依据。旧定稿保留。

### 5.1 本月人员与考勤核对

源码候选中，人员只认“本月明确参与名单”：请核对后逐行填写需要纳入的人员。模板发现的姓名和历史名单仅列作候选，不自动填入；已有明确名单不会因任何资料上传扩员。名单外默认不纳入，不设姓名特例或永久黑名单。无明确名单不能计算；以后明确修改名单或使用原“添加人员”入口仍可生成新记录，旧历史保留。独立切月后重新确认名单，旧名单仅供参考。

绑定期次的数据月份只读；换月在上方切期，独立工时仍可选月。上传考勤后先查看“待核对考勤”：自动识别失败仍保留副本，核对工作表、姓名和日期行列后点“验证手动映射”，通过后再“采用此考勤”。有主考勤时普通上传会添加补充来源；“重新选择主考勤”仅在采用后替换主来源，保留补充资料。取消待采用输入保留旧来源及上传副本，不做文件删除。

待采用时不可计算；可保存输入草稿，重新打开后须再次验证映射。改变映射也须重新验证。异工作/异期/异月草稿保持原存储但不载入，历史记录不串期。此批尚未完成浏览器交互验收，刷新当前日常页面不会自动获得修复；当前运行状态见开发进度。

### 5.2 本月项目月报

在“本月项目月报”独立入口上传XLSX，不要上传到部门模板入口。核对候选的来源行、项目名、建设单位、本月进度及办理年月；标题仅写月份时，年份由你核对确认。勾选需要的项目，选择或填写正式名称，再逐项勾选确认。模板明确项目及经营明细只是参考；精确或模糊建议都不会自动采用，没有匹配时可人工填写，多行合并同一名称须单独确认。建设单位不是合同客户，未载明合同保持未知。

如需将月报名用作考勤简称，逐项明确勾选；与已有简称冲突时先人工核对，程序不会覆盖。点“采用已确认项目”后只补入清单，人员参与仍须逐人确认，不会给全员分配全部月报项目，也不直接计算工时。100%完成或进度写到28日不作为删项目或补月底事实的依据。

取消保留原清单和上传副本；替换保留原项目及此前来源，需删旧项目时在当前清单手工核对。重复上传可重新核对，不重复添加同名清单项。模板在月报前后上传均保留已有项目和参与关系；后上传模板后可点击“重新核对此月报”，读取当前模板名称再逐项确认，不需重复上传文件。无月报可继续手工录入。待采用期间不能计算，草稿恢复后重新读取来源、确认月份和名称；不同期次不载入旧候选。来源替换历史保留上限10份，超限会提示核对，不自动清掉旧记录。合成资料的浏览器验收和实际加载版本见[开发进度](../../DEVELOPMENT_PROGRESS.md)。

### 5.3 工作关联记录

在工作详情的“关联工作记录”卡片可查看最多 5 条明确关联到该工作的有效记录。点击摘要后进入该工作范围的记录页，同时打开所选记录的来源与更正历史。关闭详情后留在该记录页；要回到工作详情，点击“返回工作名”。“查看全部关联记录”进入同一范围的列表。切换工作会重置其他筛选和页码，默认全部列表包含未关联记录。无效或已删除的工作显示范围错误。当前工作筛选主要列在用工作，已归档工作的已有链接仍可查看关联记录。

筛选只影响列表，新记录须在上方补充信息中明确选择关联；不自动继承当前筛选。记录与项目名相似也不会自动合并。查看关联不改变期次、阶段、清单或完成状态；列表条数不是完成事项数。详情显示存储进度。外部移走、恢复或替换资料后，点击详情的“重新核对材料与进度”：它会按当前磁盘文件更新影像数量、清单状态及完成时间、工作进度，不改变阶段/期次办理状态或历史定稿；普通刷新页面只读取已有值。核对中等待完成，失败可直接重试，未保存表单输入保留且不参与核对。系统内上传、删除、恢复及定稿标记变更会同步关联工作，无需改无关字段或重启纠正计数。恢复或定稿/取消定稿若收到同步失败响应，其主动作和派生数据会一起回滚；排除故障后重试原操作。恢复成功后再次恢复仍提示“不在回收站”，定稿同值重复则提示无需修改；这与首次失败后的重试不同。网络中断而未收到明确响应时，先查看当前状态，不据超时猜测成功或失败。

助手的“历史对话”列出最近更新的 50 个会话。选择一项可查看原消息并继续提问。“业务问答记录”可单独展开核对问题及证据。未发送的内容可通过“保存并离开”留在当前浏览器标签页，返回对应会话后可继续编辑。业务范围以输入区实际选中的工作和期次为准。消息读取失败时可点击重试。对话用 Enter 发送，Shift+Enter 换行。

侧栏“配置模型”可直接进入“模型与资料”。按用途展开配置，输入的密钥默认隐藏；显式显示仅限本次输入。切换设置栏目后会恢复各自的滚动位置，资料维护和 OCR 按需展开。

## 6. 模板和资料

文件库分类栏的“前往模板库”进入知识库；需要筛当前文件列表时使用文件类别。查看文件的大小和版本状态时分别读对应标示。模板库可先选分类，再选列表中的资料。详情区可核对模板格式、更新时间、变量和校验状态，并打开对应操作。列表区分在用为空、归档为空和没有符合筛选的结果。在用模板可“归档”，如需取回到“查看归档”恢复。变量数为 0 的已有扫描结果与暂无变量清单分别显示。字段映射还有其他结果时才显示“显示更多”。

在非期次工作的“本次业务内容”中，保存后继续输入的文字仍是待保存稿。保存失败可重试；遇到另一窗口已保存不同正文时，先核对两份文字再决定采用哪份。点击生成会先保存当前正文；若保存期间又修改，核对最新内容后再点生成。

“选择 / 调整模板”可暂时收起，重新展开能继续勾选。离开前可继续编辑、保存或放弃。编辑高级排期时可以补齐期次；若另一窗口先保存，核对冲突提示中两份规则，选择“保留本页修改并核对”可保留本页改过的字段，再点保存。历史期次仍可查看原有要求。

浅色桌面源码候选的知识库默认展示模板库，可切换字段映射；变量、循环和图片说明在“模板使用说明”中展开。制度不在日常知识库展示；需要维护时到“系统配置→模型与资料→后台参考资料维护”，可使用原入库文档、找文件、检索提问和查依据。折叠保留当前维护状态。文书的“依据”弹窗仍能看原文和被引文书；“后台参考资料”直接打开设置并展开维护区，刷新可保留该目的地，但不会定位具体条款。仅移动入口，不删除资料或自动开启制度引用；仍须本次明确提出参考制度。此说明适用于对应源码候选，本机实际加载的构建见健康接口。

模板是空白结构及填写规则，不是已经发生的事实。目录筛选用于寻找模板，同一模板可适用于多个流程。不要仅凭模板名称改变工作类型。

制作细节见[模板制作指南](../03-模板制作指南.md)，以当前模板引擎和实际产物检查补充旧指南。Word变量使用单一格式运行中的 `{变量名}`；Excel循环/集合行须在数据区末尾且不合并、不含公式，不在后面放页脚。

上传后检查变量、示例生成和实际版式；不能只做文件盘点就宣称模板可用。外部真实原件保留，参考目录只读。

## 7. 常见问题

| 现象 | 处理 |
|---|---|
| 模型未配置或请求失败 | 保存草稿并人工编辑，确认设置和资料使用范围，不自行复制凭证或改用外部服务 |
| 生成后仍有“待确认” | 看模板列出的缺项；不是每份模板都只需要核心五项事实 |
| 旧文件显示待更新 | 核对来源/模板/记录变化，再生成新版本；旧稿可保留参考 |
| 日期或结果不知道 | 保持未知并下载待确认稿，不填“无问题”凑齐 |
| 进入不了或界面版本不符 | 按运维手册核对日常服务、source-current.json 和配套前端，通过同一日常入口打开 |
| 删除出现错误 | 保留提示与对象范围，停止重复永久删除，按GOV-01隔离排查；不要手工清理数据库 |

## 8. 提交有效反馈

记录要完成的业务、工作/期次范围（必要时匿名）、操作步骤、期望与实际、错误提示、时间、是否保留输入及文件。提供资料时按需脱敏；不要包含模型密钥。当前待验收项见[质量计划](../management/QUALITY_AND_ACCEPTANCE.md)。
