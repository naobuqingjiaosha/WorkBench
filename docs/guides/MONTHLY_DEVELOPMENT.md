## 日常入口与发布边界

已发布并启动，可刷新[本机工作台](http://127.0.0.1:8787)。以后仍用 `npm start` / `启动工作台.cmd`。原工作、期次与文件保留，开发样例没有导入日常数据库。工时从原部门工时工作进入；清廉月检从原月检期次的年度台账入口进入。

用户已明确工时应为整数，但要求本次不修改；本版自动分配仍可能产生小数，原9月文件未重做。详见[发布报告44](../44-月度工时与年度台账发布-2026-10-21.md)。

## 隔离开发启动与数据边界

在仓库根目录运行：

```powershell
npm run dev:monthly -- --build --seed-handoff
```

开发版使用 `http://127.0.0.1:18889`，数据库、管理文件及前端均位于 `.tmp/monthly-development`。重复启动保留已有编辑；已经存在开发数据时不会重复导入。已有服务占用该端口时先在对应终端 Ctrl+C 停止。单独启动已有构建：`npm run dev:monthly`。

`--seed-handoff` 使用本次已解包、已规范化的资料副本；不向原始业务目录写入。临时资料不随 Git 分发，另一台机器需从页面重新导入资料。不要把普通 `npm run dev` 的默认代理误接到日常8787做写入测试。

本机已准备两个开发工作：

- 工时：`http://127.0.0.1:18889/#/workbench?task=timesheets&id=1&periodId=10&runId=1`。
- 月检：`http://127.0.0.1:18889/#/workbench?id=2&periodId=20`。

地址中的编号仅适用于本次预置开发库。其他环境从工作列表进入对应工作、月份即可。

## 月度工时操作

1. 进入部门工时工作，选择月份。页面顶端分别上传研发工时、员工/外包考勤、统一模板或上期部门表；也可选择现有模板库。
2. 核对人员、当月参与项目。初始名单参考9月；康涛涛暂排除。加入人员后的名单持久保存，下月可沿用并按实际情况调整项目。
3. 核对实际应计薪日期。系统从研发有工时日期给出候选，不按星期自动认定出勤。确认研发资料完整后生成。未告知扣薪按满工时；扣薪例外按人日填写。考勤项目简称可映射到本月项目。
4. 在人员/逐日结果中修改，或让模型提出修改、核对后采用。项目份额调整须保持当日总数；减总数须有扣薪例外。其他已保存逐日修改保留。
5. 重新计算后导出 Excel，在本地核对，再保存定稿。项目线索警告不阻断满工时核验，但日期、缺失资料、总数不符等阻断定稿。生成和定稿不代表已经交给财务。

XLS伪装成XLSX的旧考勤需要本机安装 Microsoft Excel，程序保留原始副本并通过隐藏实例转换，不运行宏和外部链接。PDF考勤尚不自动转换成计薪数据，需先提供可核对的表格。

## 清廉工程月检操作

1. 在月检期次的“年度台账与月度检查”导入年度Excel。开发库已预置年度台账及两张实际模板副本；日常库未导入测试资料，首次使用需导入/绑定自己的台账并选择两张模板。若要使用原目录文件，先在工作详情绑定目录，再填写其中的台账路径；绑定时保存原版本并写入内部关联。
2. 选项目查看历史，新增本月检查，填写事项和实际情况。允许同项目同月多条；日期不明保持空白。新项目可在此加入，小微权力只勾选同一记录的标记，按月显示2条核对。
3. 保存编辑；模型只提出表述建议，采用后再保存。未知问题、结果等留空，不自动写成“未发现问题”。“确认实际检查”与“生成两个表”是不同动作。
4. 两个表从同一条台账记录生成。工作记录表的“检查内容”取监督事项，“检查结果”取发现问题；监督表取项目+事项、具体内容、发现问题、整改、备注以及实际人员/单位/时间。
5. 点“本地打开”，在Excel保存后点“读取保存后的修改并同步”。页面打开、重新获得焦点和每15秒会检查文件变化；同步写回由按钮执行，生成前也会先同步。发现冲突时选择保留工作台或对应文件内容。先保存页面编辑再同步。
6. 已签字文件可保留历史版本；后续修改生成新版本。原有报送状态不自动改变。历史文件关联缺失、复制重复关联、跨项目移动行等会停止写回并提示核对，不能自动猜测修复。

完整Excel编辑在本地完成。网页只编辑已映射的业务字段，不是完整Excel编辑器。只支持交接资料中已验证的台账和两种表格结构；任意移动列、改名或改造模板需重新确认映射。下载件是副本；需要回写请编辑“本地打开”指向的管理/绑定文件。修改本机之外另存的下载副本不会自动同步。

季度、年度资料收集可引用年度台账；历史导入/草稿/修改待确认作为参考，明确确认的记录才计入检查统计。来源或关联文件变化会使旧证据快照失效。
