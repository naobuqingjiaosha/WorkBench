# 月度工时与年度台账操作及开发验收

文档ID：GUIDE-MONTHLY-DEV。更新：2026-11-10。适用范围：GOV-12 源码候选。各设备加载版本见[开发进度](../../DEVELOPMENT_PROGRESS.md)。

## 进入办理

从“我的工作台”选择部门工时或月度检查工作，再选择相应月份。试用候选时用 `预览候选工作台.cmd`，让样例和草稿留在该候选的独立资料根。开发时可运行 `npm run dev:monthly -- --build`，使用 development 下的 monthly 根及默认 18889 端口。

## 月度工时操作

1. 进入部门工时工作，选择月份。页面顶端分别上传研发工时、员工/外包考勤、统一模板或上期部门表；也可选择现有模板库。
2. 核对本月明确参与名单及各人项目。当前源码候选把模板姓名和历史偏好仅作为参考，不自动纳入；名单外默认不计入，空名单须先人工确认。已有草稿/历史名单保持，上传不扩员；以后明确改名单可生成新记录。无姓名专属默认排除，独立切月重新核对，不把历史名单直接当作本月确认。操作见[使用说明](USER_GUIDE.md)。
3. 核对实际应计薪日期。系统从研发有工时日期给出候选，不按星期自动认定出勤。确认研发资料完整后生成。未告知扣薪按满工时；扣薪例外按人日填写。考勤项目简称可映射到本月项目。
4. 在人员/逐日结果中修改，或让模型提出修改、核对后采用。项目份额调整须保持当日总数；减总数须有扣薪例外。其他已保存逐日修改保留。
5. 重新计算后导出 Excel，在本地核对，再保存定稿。若模板已有总计，核对新项目行和新增日期列是否进入原合计范围，并与人员和逐日数据对账。出现“模板公式”异常时，提示中会给出工作表、地址和原式；在模板副本中明确引用范围后重新导入、计算。修前保存的未定稿版本需选择“重新计算并保存”。只分配整小时。不能同时满足当日总量与整数分配时，保留异常并核对来源，再生成新版。生成和定稿不代表已经交给财务。

XLS伪装成XLSX的旧考勤需要本机安装 Microsoft Excel，程序保留原始副本并通过隐藏实例转换，不运行宏和外部链接。PDF考勤尚不自动转换成计薪数据，需先提供可核对的表格。

## 清廉工程月检操作

1. 在月检期次的“年度台账与月度检查”导入年度Excel。首次使用需导入/绑定自己的台账并选择两张模板。若要使用原目录文件，先在工作详情绑定目录，再填写其中的台账路径；绑定时保存原版本并写入内部关联。
2. 选项目查看历史，新增本月检查，填写事项和实际情况。允许同项目同月多条；日期不明保持空白。新项目可在此加入，小微权力只勾选同一记录的标记，按月显示2条核对。
3. 保存编辑；模型只提出表述建议，采用后再保存。未知问题、结果等留空，不自动写成“未发现问题”。“确认实际检查”与“生成两个表”是不同动作。
4. 两个表从同一条台账记录生成。工作记录表的“检查内容”取监督事项，“检查结果”取发现问题；监督表取项目+事项、具体内容、发现问题、整改、备注以及实际人员/单位/时间。
5. 点“本地打开”，在Excel保存后点“读取保存后的修改并同步”。页面打开、重新获得焦点和每15秒会检查文件变化；同步写回由按钮执行，生成前也会先同步。发现冲突时选择保留工作台或对应文件内容。先保存页面编辑再同步。
6. 已签字文件可保留历史版本；后续修改生成新版本。原有报送状态不自动改变。历史文件关联缺失、复制重复关联、跨项目移动行等会停止写回并提示核对，不能自动猜测修复。

完整Excel编辑在本地完成。网页只编辑已映射的业务字段，不是完整Excel编辑器。只支持交接资料中已验证的台账和两种表格结构；任意移动列、改名或改造模板需重新确认映射。下载件是副本；需要回写请编辑“本地打开”指向的管理/绑定文件。修改本机之外另存的下载副本不会自动同步。

季度、年度资料收集可引用年度台账；历史导入/草稿/修改待确认作为参考，明确确认的记录才计入检查统计。来源或关联文件变化会使旧证据快照失效。

## 复验与业务核对

`npm run test:monthly` 用合成工作簿验证日历、人员范围、研发先扣、扣薪、项目分配、重算、人工版本和关联定稿。实际页面用 `node scripts/test-isolated.mjs --shared timesheet-browser`；工具配置见[开发指南](DEVELOPMENT.md)。新导出的研发数据取当期来源；研发项目缺少当期依据时不沿用旧表的项目归属。

候选使用 LibreOffice 检查样例重算和页面打印。Windows Microsoft Excel 的实际重算、打印设置、旧 XLS 转换和真实人员逐日核账仍需在目标机核验。原工作簿、既有定稿及历史凭证保持原版。历史限定发布的日期与范围见[发布报告44](../44-月度工时与年度台账发布-2026-10-21.md)。
